# ARCHITECTURE

## 1. 总体结构

```text
50 MHz Clk
   │
   ├── tick_gen ─────────────→ tick_1s / blink_tick
   │
4 Keys ─→ key_filter ×4 ─────→ key events
   │
4 SWs ───────────────────────→ mode select
   │
   ├── datetime_core ────────→ hour/min/sec/year/month/day
   ├── alarm_core ───────────→ alarm state / LED request
   ├── countdown ────────────→ countdown time / done state
   ├── stopwatch ────────────→ stopwatch time
   │
   └── display_ctrl ─────────→ 32-bit display data + display flags
                                  │
                                  ↓
                              LED_disp
                                  │
                                  ↓
                              LUT + SEL
```

最外层模块统一由 `watch_top.v` 完成连接。

## 2. 模块职责

### `tick_gen.v`
- 输入：50 MHz 系统时钟、复位；
- 输出：1 秒节拍；
- 后续可增加较低频率闪烁节拍；
- 仿真时通过 parameter 缩短计数周期，避免仿真等待过长。

### `datetime_core.v`
- 保存当前时、分、秒、年、月、日；
- 完成正常时间推进；
- 处理 23:59:59 跨天；
- 识别大小月和闰年；
- 接受设置模式产生的调整事件。

### `key_filter.v`
- 每个物理按键实例化一次；
- 完成机械按键消抖；
- 输出单次按下事件，避免一次按键被识别为多次操作。

### `alarm_core.v`
- 保存三个闹钟时间和启用状态；
- 比较当前时间与闹钟时间；
- 使用 FSM 实现第一次 5 秒提醒、10 秒等待、第二次 5 秒提醒；
- 输出 LED 提醒请求。

### `countdown.v`
- 保存预设倒计时时间和当前剩余时间；
- 支持设置、开始、暂停、继续/重启；
- 到 00:00 后请求 LED 闪烁 5 秒。

### `stopwatch.v`
- 扩展模块；
- 从 00:00.00 正向计时；
- 支持开始、暂停、继续和清零。

### `display_ctrl.v`
- 根据工作模式选择当前显示内容；
- 负责字段闪烁、分隔符等界面逻辑；
- 不直接驱动具体数码管引脚。

### `LED_disp.v`
- 8 位数码管动态扫描；
- 输入统一显示数据，输出 `LUT[7:0]` 与 `SEL[7:0]`；
- 尽量复用课程实验中已经验证过的实现。

### `watch_top.v`
- 顶层模块；
- 实例化并连接所有模块；
- 顶层端口应尽量只包含开发板真实外部资源。

## 3. 设计原则

1. 一个模块只承担一类主要职责；
2. 各功能通过事件/状态接口连接，不跨模块直接操作内部寄存器；
3. 内部统一以 24 小时制保存时间，12 小时制仅作为显示层转换；
4. 时间推进尽量由单一时钟域完成，避免人为生成多个新时钟；
5. 功能模块先单独仿真，再接入 `watch_top`；
6. 修改模块接口时同步更新本文件和 `DECISIONS.md`。

## 4. 建议验证边界

- 12:34:59 → 12:35:00；
- 23:59:59 → 00:00:00 并日期 +1；
- 30 天月、31 天月切换；
- 平年 2 月与闰年 2 月；
- 12 月 31 日跨年；
- 闹钟第一次提醒 / 手动解除 / 二次提醒；
- 倒计时 00:01 → 00:00；
- 长按按键不能被误认为多次无控制输入。
